## 🌌 Welcome Contributors

Thank you for contributing to the open-source **UI/UX Architecture & Design System** of **MetaRang (متارنگ)**. All design tasks are managed transparently via GitHub Issues, and every merged contribution permanently records your name, portfolio, and MetaRang Citizen ID (`HM-xxxx`) in the official project registry.

## 📋 Mandatory Contribution Rules

1. **Base Reference Standard (`Dark Mode + RTL Persian`):** Every new screen, modal, or component **must** first be designed and delivered in **Dark Mode** and **RTL (Persian)**. `Light Mode` and `LTR` variants are localized subsequently.
2. **Synchronized Versioning:** All file names must match MetaRang's technical versioning (e.g., `v1.1.26`).
3. **Mandatory Design System Sync (`00-design-system/`):** Any new or modified colors, tokens (`.json`), or vector icons (`.svg`) must be updated inside `00-design-system/` within the same Pull Request.
4. **Personal Figma Public Link:** Create your design in your personal Figma workspace, set permissions to **Public ("Anyone with the link can view")**, and include the link in the target directory's `README.md` and your PR.
5. **Citizen Identity Registration (`05-contributors/`):** Register your profile file named after your MetaRang Citizen ID (e.g., `HM-2000007.json`) using `TEMPLATE-contributor.json`.

# 🤝 راهنمای مشارکت در طراحی رابط کاربری و سیستم دیزاین متارنگ
### دستورالعمل اجرایی طراحی متن‌باز، تحویل فایل‌ها (Handoff) و ثبت مشارکت

از علاقه‌مندی شما به مشارکت در توسعه متن‌باز **معماری رابط کاربری و سیستم دیزاین متارنگ (MetaRang)** سپاسگزاریم. تمامی نیازهای طراحی به صورت شفاف در قالب **Issue** تعریف می‌شوند و پس از تایید و ادغام، نام، پورتفولیو و شناسه شهروندی شما (`HM-xxxx`) به صورت دائمی در بانک مشارکت‌کنندگان متارنگ ثبت خواهد شد.

## 📋 قوانین الزامی مشارکت

1. **استاندارد نسخه پایه (`Dark Mode + RTL فارسی`):** تمامی صفحات و کامپوننت‌های جدید **الزاماً** باید ابتدا در وضعیت **Dark Mode** و جهت **RTL (زبان فارسی)** طراحی و تحویل شوند. نسخه‌های `Light Mode` و `LTR` بر پایه نسخه مرجع تکمیل می‌شوند.
2. **هماهنگی نسخه‌بندی:** نام‌گذاری فایل‌ها باید دقیقاً از نسخه‌بندی فنی متارنگ (مانند `v1.1.26`) تبعیت کند.
3. **به‌روزرسانی هم‌زمان سیستم دیزاین (`00-design-system/`):** هرگونه تغییر در پالت رنگی، توکن‌های طراحی (`.json`) یا افزودن آیکون‌های برداری (`.svg`) باید **در همان Pull Request** در پوشه `00-design-system/` اعمال شود.
4. **لینک عمومی فایل Figma شخصی:** طرح خود را در فیگمای شخصی ایجاد کرده، دسترسی آن را روی حالت عمومی (**Anyone with the link can view**) قرار دهید و لینک آن را در توضیحات PR و `README.md` پوشه مقصد ثبت نمایید.
5. **ثبت پرونده هویت شهروندی (`05-contributors/`):** یک فایل با نام شناسه شهروندی خود (مثال: `HM-2000007.json`) بر اساس فایل الگو (`TEMPLATE-contributor.json`) ایجاد و مشخصات خود را ثبت کنید.
