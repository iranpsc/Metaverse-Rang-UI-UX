## 🌌 Welcome Contributors

Thank you for contributing to the open-source **UI/UX Architecture & Design System** of **MetaRang (متارنگ)**. This repository enforces automated DesignOps governance via **GitHub Actions** so that every contribution meets international portfolio standards, maintains a clean directory tree, and permanently records your **MetaRang Citizen ID (`HM-xxxx`)** in `05-contributors/`.

## 🔄 Step-by-Step Contribution Flow

1. **Open a Structured Task Issue (`ui-task.yml`):**
   - Select **Task Type**: `new-directory` (for brand-new screens) or `enhance-existing` (to automatically create the next version `-v2`, `-v3`, ... alongside existing files without deleting previous work).
   - Specify the target **Version**, lowercase `kebab-case` **Directory Slug** (locked after creation), **Categories/Platforms**, **Themes**, **Directions** (`rtl` is always generated by default; `ltr` is optional), and **Languages** (`fa`, `en`).
   - Provide detailed bilingual specifications (English + Persian).
2. **Wait for Auto-Scaffolding Merge:**
   - GitHub Actions (`issue-scaffold.yml`) automatically creates `<category>/<platform>/<theme>/<direction>/<slug>/<lang>/README.md` and opens a Pull Request to `main`.
   - Once `@iranpsc/ui-ux-manager` approves and merges the scaffold PR, the target directories become live on `main`.
3. **Submit Your Design Pull Request to `main`:**
   - Place all deliverables strictly inside the pre-existing Issue-scaffolded directories.
   - **Never create new directories** or **delete previously merged design files** inside a PR.
   - Register/update your profile in `05-contributors/HM-xxxx.json` using `TEMPLATE-contributor.json`.
   - Sync any new colors/typography tokens (`.json`) or icons (`.svg`) inside `00-design-system/`.
4. **Pass Automated PR Quality Gate (`pr-guard.yml`) & Final Review:**
   - Include `Closes #<issue>` or `Refs #<issue>` and a valid public **Figma URL** in the PR description.
   - Follow lowercase `kebab-case` filenames (no spaces, uppercase, or Persian characters).
   - Respect file size limits: **max `5 MB`** for 2D/doc files (`.png`, `.jpg`, `.jpeg`, `.gif`, `.svg`, `.pdf`, `.json`), and mandatory **Git LFS** for `.glb`, `.fbx`, and any file above **`10 MB`**.
   - Obtain final visual review & approval from `@iranpsc/ui-ux-manager`.

# 🤝 راهنمای مشارکت در طراحی رابط کاربری و سیستم دیزاین متارنگ
### دستورالعمل اجرایی DesignOps خودکار، تحویل فایل‌ها (Handoff) و قوانین کنترل کیفیت

از علاقه‌مندی شما به مشارکت در توسعه متن‌باز **معماری رابط کاربری و سیستم دیزاین متارنگ (MetaRang)** سپاسگزاریم. این مخزن با استفاده از **GitHub Actions** به‌صورت هوشمند و خودکار مدیریت می‌شود تا تمامی مشارکت‌ها در سطح استاندارد بین‌المللی ثبت شده و نام و شناسه شهروندی شما (`HM-xxxx`) به‌صورت دائمی در `05-contributors/` بایگانی شود.

## 🔄 مراحل گام‌به‌گام مشارکت

1. **ثبت ایشوی استاندارد تسک (`ui-task.yml`):**
   - **نوع فعالیت** را انتخاب کنید: `new-directory` (برای ایجاد طرح جدید) یا `enhance-existing` (برای توسعه طرح موجود با ساخت خودکار نسخه بعدی `-v2`، `-v3` و... بدون حذف فایل‌های قبلی).
   - نسخه هدف، نام دایرکتوری (اسلاگ انگلیسی با حروف کوچک و خط تیره — پس از ثبت قفل می‌شود)، دسته‌بندی/پلتفرم، تم، جهت (نسخه `rtl` همیشه پیش‌فرض است) و زبان‌ها (`fa`، `en`) را مشخص کرده و توضیحات دوزبانه بنویسید.
2. **تایید و مرج دایرکتوری‌های ساخته‌شده توسط ربات:**
   - اکشن `issue-scaffold.yml` به‌صورت خودکار مسیر `<category>/<platform>/<theme>/<direction>/<slug>/<lang>/README.md` را ساخته و یک PR به شاخه `main` باز می‌کند.
   - پس از تایید و مرج این PR توسط تیم `@iranpsc/ui-ux-manager`، دایرکتوری مقصد آماده دریافت فایل‌های طراحی خواهد بود.
3. **ارسال Pull Request فایل‌های طراحی به شاخه `main`:**
   - فایل‌ها را **صرفاً** در دایرکتوری‌های از پیش ایجادشده و دارای `README.md` قرار دهید.
   - **ساخت دایرکتوری جدید** و **حذف فایل‌های طراحی‌شده قبلی** در PR اکیداً ممنوع است.
   - پرونده هویت شهروندی خود (`05-contributors/HM-xxxx.json`) و تغییرات سیستم دیزاین (`00-design-system/`) را هم‌زمان به‌روزرسانی کنید.
4. **عبور از گیت‌کیپر خودکار (`pr-guard.yml`) و تایید نهایی:**
   - شماره ایشو (`Closes #<num>` یا `Refs #<num>`) و لینک عمومی **Figma** را در توضیحات PR ثبت کنید.
   - نام تمامی فایل‌ها باید با حروف کوچک انگلیسی و خط تیره (`kebab-case`) باشد (بدون فاصله، حروف بزرگ یا کاراکتر فارسی).
   - سقف حجم فایل‌های دوبعدی و مستندات **۵ مگابایت** است؛ فایل‌های سه‌بعدی (`.glb`, `.fbx`) و فایل‌های بالای **۱۰ مگابایت** باید با **Git LFS** ثبت شوند.
   - پس از پاس شدن چک‌های خودکار، تایید نهایی و مرج توسط تیم `@iranpsc/ui-ux-manager` انجام می‌شود.
