## English Specification



### Delivery & Quality Standards
- **Allowed Assets:** `.png`, `.jpg`, `.jpeg`, `.gif`, `.svg`, `.pdf`, `.json`, `.glb`, `.fbx`
- **Naming Convention:** Lowercase `kebab-case` only (no spaces, uppercase, or non-ASCII characters).
- **Size & LFS Policy:** Max `5 MB` for 2D/document files; Git LFS is mandatory for `.glb`, `.fbx`, and any file above `10 MB`.
- **PR Requirements:** Must reference `Closes #3` (or `Refs #3`), include a valid Figma URL, and receive approval from `@iranpsc/ui-ux-manager`.
